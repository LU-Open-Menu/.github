### Key Capabilities & Methods

* **One-Click Auto Remove:** Extracts localized system and keychain tokens via encrypted backup routines to send an FMI unbinding request to Apple's servers without requiring a jailbreak.
* **Game Center & Media Sign-In Refresh:** Uses **Settings > Game Center** or **Settings > [Apple ID] > Media & Purchases** toggles to force fresh authentication token generation prior to running the removal script.
* **Built-In Backup Engine:** Automates encrypted backup parsing internally, removing the need for external extraction utilities like Elcomsoft or 3uTools on standard runs.
* **Manual XML Fallback:** Supports importing manually extracted XML keychain files if an encrypted backup password was previously configured on the device.

### Setup & Operational Workflow

1. **Install Official iTunes & Extract Tool:** Prerequisite driver installation.
Install **iTunes for Windows** using Apple's standalone web installer so the required `Apple Mobile Device USB Drivers` are present. Extract the `LU Open Menu Tool` archive to the root of your `C:\` drive (e.g., `C:\LU_OpenMenu\`).

*Verification:* Open Windows **Device Manager** (`devmgmt.msc`) and verify that connecting your iPhone displays `Apple Mobile Device USB Driver` under `Universal Serial Bus controllers` without warning icons.


2. **Prepare the Open Menu iOS Device:** Device preparation.
Ensure the iPhone or iPad is connected to stable Wi-Fi, has no Screen Time / Restrictions lock blocking account changes, and has unnecessary photos or large videos cleared to speed up the local backup scan.

*Verification:* Confirm you can open **Settings**, tap the Apple ID banner at the top, and access **Media & Purchases** or **Game Center**.


3. **Launch Utility & Register Serial Number:** Registration & launch.
Right-click the LU Open Menu executable and select **Run as Administrator**. Connect the unlocked iOS device via a reliable USB cable and tap **Trust This Computer** on the screen. Copy the device Serial Number / ECID shown in the tool and register it through an authorized reseller if not yet activated.

*Verification:* Clicking **Read Info / Check Compatibility** confirms the device model, iOS version, and `FMI: ON` status.


4. **Trigger Token Refresh & Execute FMI Off:** Execution & restore.
Depending on the iOS build, toggle **Game Center** OFF and ON (or sign out and back into **Media & Purchases**, then enable Airplane Mode) as instructed by the tool prompt, and click **Auto Remove / FMI OFF**. Once the server status changes to `FMI: OFF`, perform a full **DFU / iTunes Restore** to permanently clear the old Apple ID from the device.

*Verification:* Check the device serial number on an official IMEI/SN status checker to confirm `Find My iPhone: OFF` before restoring.
